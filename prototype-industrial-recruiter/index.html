GT-ACT

G-code / setup sheet

Cycle-time analysis and setup-sheet automation for NC handoff.

  • Parses G-code movement by N-block for review.
  • Checks tool length against Z-depth before production.
  • Exports standardized Excel and PDF setup sheets.
PythonpandasopenpyxlPDF export

GT-PATH

offline viewer

Offline NC and G-code path viewer for quick inspection without CAM setup.

  • Handles G0, G1, G2, G3, canned cycles, units, and offsets.
  • Shows travel, stock, fixture boxes, and rapid-move risk.
  • Runs fully offline from local HTML, CSS, and JavaScript.
PySide6JavaScriptHTML/CSSNC parser

GT-FIXSYS

fixture workflow

Fixture requisition and monitoring system for tool-room visibility.

  • Covers monitor, requisition, master data, and admin flows.
  • Uses scan-based borrow and return actions with exact code matching.
  • Tracks available, pending, overdue, missing, obsolete, and deleted states.
